# Frontend ↔ API mapping

Every endpoint the Vue SPA calls (from [`backend-api-contract.md`](backend-api-contract.md)), mapped to the Laravel route, controller action and the middleware that **actually enforces** access. Generated by `python scripts/generate-frontend-api-mapping.py` from `php artisan route:list`; regenerate after route changes.

- Base URL: `{VITE_API_BASE_URL}` = `https://api.pilotwardrobe.com/api/v1`. All paths below are relative to it.
- **auth** = Sanctum (session cookie or bearer token) and `EnsureAccountUsable` (suspended accounts and revoked sessions are rejected). **staff** = admin or super-admin. **perm** = the effective permission must be held (`a|b` any of, `a,b` all of). **idempotent** = honours the `Idempotency-Key` header (replays return the original response). Every `/api/v1` route also has the global `api` throttle (120/min).
- Ownership (my order, my listing…) is enforced inside the action, which returns **404** for records the caller cannot see.
- Request/response bodies: [`api-payloads/`](api-payloads/README.md). Field-level comparison: [`payload-compatibility-audit.md`](payload-compatibility-audit.md).
